# AeroJet Executive Aviation - Versão CNPJ 64.941.848/0001-06

Esta pasta contém uma variação do site institucional da **AeroJet Executive Aviation**, adaptada para uso com o CNPJ **64.941.848/0001-06** e com textos ligeiramente diferentes da versão base, preservando o layout e a identidade visual original.

## Visão Geral

O site apresenta a empresa, sua frota de jatos executivos e serviços de fretamento e gestão de aeronaves, com foco em exclusividade, segurança e agilidade na operação.

-   **Tecnologias:** HTML5, CSS3, JavaScript (ES6+)
-   **Design:** Luxuoso e tecnológico, com paleta azul marinho e prata metálico.
-   **Layout:** Responsivo (Mobile-First) e otimizado para campanhas e presença institucional.

## Funcionalidades

O arquivo `js/script.js` mantém as mesmas funcionalidades da versão original:

1.  **Header dinâmico:** muda de aparência ao rolar a página.
2.  **Menu mobile:** ícone hambúrguer com animação de abertura e fechamento.
3.  **Scroll suave:** navegação entre seções usando âncoras.
4.  **Simulação de envio de formulário:** feedback visual ao solicitar um itinerário.
5.  **Animação dos cards de frota:** cartões surgem com transição suave ao entrar na tela.
